# 客户端脚本

该目录存放可被 OCS 桌面端或用户脚本管理器加载的客户端辅助脚本。

## `sisu-ocs-client-bridge.user.js`

用于 OCS 官方脚本无法识别部分定制学习平台题目时的桥接场景。脚本会在页面右下角显示一个小面板，手动点击后从当前页面可见题目中提取题干、选项和题型，请求本项目的 `/ocs/query` 接口，再把答案回填到当前页面控件。自动答当前页默认关闭，需要用户在面板里主动勾选。

使用方式：

1. 在 OCS 桌面端打开“脚本列表”。
2. 点击“添加本地脚本”。
3. 选择本目录下的 `sisu-ocs-client-bridge.user.js`。
4. 进入学习平台题目页后，在右下角面板配置服务地址和 API Key。
5. 点击“识别题目”或“答当前页”。

安全边界：

- 脚本只回填当前页面可见题目，不点击平台提交按钮。
- 自动答题默认关闭，开启后也只处理当前可见题目。
- API Key 只存储在当前浏览器脚本环境的 `localStorage` 中，不写入仓库。
- 识别规则偏保守，平台 DOM 改版后应先用“识别题目”检查抽取结果。

## OCS 一直卡在“正在安装用户脚本”

如果 OCS 导航页一直显示“正在安装用户脚本”，说明脚本还没有进入浏览器脚本管理器执行阶段。此时不是本桥接脚本的识别逻辑出错，而是 OCS 桌面端的浏览器扩展或网络脚本安装流程卡住。

建议按顺序处理：

1. 在 OCS 桌面端“脚本列表”里临时关闭官方“OCS 网课助手”的“自动安装”，再重启 OCS 浏览器。
2. 进入 OCS 桌面端“软件设置”，执行环境检测或自动修复。
3. 打开浏览器地址栏的 `chrome://extensions`，确认脚本管理器扩展已经安装并启用。
4. 如果仍然卡住，切换 OCS 设置里的浏览器路径，优先使用 OCS 推荐的内置 ChromeForTesting 或本机稳定版 Chrome。
5. 等导航页不再显示“正在安装用户脚本”后，再加载本地 `.user.js`。

只有当浏览器右上角能看到脚本管理器扩展，或学习平台页面上能看到脚本面板时，才表示本地脚本真正开始运行。
