# 数据工作区

此目录专门用于存放原始数据、暂存数据、规范化数据以及基于清单的数据管理。

## 预期的布局

```text
data/
  raw/
  staged/
  normalized/
  manifests/
```

## 当前规则

在满足以下条件之前，请勿在此处放置大型下载的数据集：

- 已检查源许可证/协议
- 已记录模式映射（schema mapping）
- 已确定所选的技术栈和存储策略

版本控制最好保留：

- 擦除敏感信息后的模板或模式说明
- 许可协议允许的样本行
- 规范化说明

避免提交：

- 未记录的批量下载数据
- 私有导出数据
- 包含密钥的 API 快照
- 包含机器特定路径、本地环境痕迹或仅运行时审计输出的本地生成验证清单

## 当前本地产物

- `raw/`：包含本地克隆的、用于开发的公共基准测试仓库。
- `normalized/cmmlu.jsonl`：从 CMMLU 生成的本地规范化导出文件。
- `manifests/cmmlu-export.json`：生成的导出数量清单。

除非以后的审查明确批准提交擦除敏感信息后的文件，否则大型本地数据产物和生成的验证清单均已被 `.gitignore` 故意忽略。
