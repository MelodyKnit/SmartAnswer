# 数据源

更新日期：`2026-06-07`

## 1. 数据源分类

潜在的数据源分为以下四组：

1. 公开基准测试数据集 (public benchmark datasets)
2. 自行整理的问答表 (self-curated QA tables)
3. 网站知识导入 (website knowledge imports)
4. 可选的外部实时查找服务 (optional external live lookup services)

对于本项目，公开基准测试数据集和自行整理的问答表应作为首要的导入目标，因为它们最容易进行审计和规范化。

## 2. 公开基准测试数据集

### 2.1 C-Eval

- 官方仓库：<https://github.com/hkust-nlp/ceval>
- 当前价值：
  - 中文单项选择题基准测试
  - 官方仓库说明包含 `52` 个学科的 `13,948` 道题目
- 推荐用途：
  - 种子数据集
  - 回归与检索评估集
- 注意事项：
  - 在将数据集打包放入代码库之前，请确认其许可证和重新分发条款

### 2.2 CMMLU

- 官方仓库：<https://github.com/haonan-li/CMMLU>
- 当前价值：
  - 广泛的中文学科覆盖面
  - 官方仓库说明包含 `67` 个主题
- 推荐用途：
  - 检索质量测试
  - 学科分类参考

### 2.3 M3KE

- 官方仓库：<https://github.com/tjunlp-lab/M3KE>
- 当前价值：
  - 面向中文教育的大型选择题集
  - 官方仓库说明包含来自 `71` 个任务的 `20,477` 道题目
- 推荐用途：
  - 种子导入候选
  - 导入压力测试

### 2.4 CMMMU

- 官方仓库：<https://github.com/CMMMU-Benchmark/CMMMU>
- 当前价值：
  - 多模态题目素材
- 推荐用途：
  - 仅在后续添加基于图像的题目支持时使用

### 2.5 AGIEval

- 官方仓库：<https://github.com/ruixiangcui/AGIEval>
- 当前价值：
  - 面向评估的基准测试
- 推荐用途：
  - 基准测试和验证参考

## 3. 自行整理的问答表格式

本项目最可靠的第一方格式为：

- `CSV`
- `XLSX`
- `JSONL`

建议的标准列名（规范列）：

- `question_id`
- `subject`
- `chapter`
- `question_type`
- `title`
- `options`
- `answer`
- `explanation`
- `tags`
- `source_name`
- `source_url`
- `source_license`

## 4. 网站知识源

目前较为强力的候选源包括：

- `MaxKB` 网站知识库导入
- `Open WebUI` 知识管理以及同步工具

适用场景：

- 静态课程笔记
- 文档页面
- 公开教育参考资料

当有结构化的问答表可用时，避免将网站导入作为客观题的首要且唯一的答案来源。

## 5. 可选的外部实时查找源

这些应该被视为可选的适配器，而不是核心依赖项。

规则：

- 必须记录数据源的出处（ provenance ）
- 响应结构必须进行规范化
- 查找失败不能破坏核心服务
- 仅使用已明确授权或公开访问的源

为什么它们的优先级较低：

- 可用性风险
- 质量参差不齐
- 法律和稳定性方面的不确定性
- 难以复现

## 6. 准入政策

在导入任何源之前，请收集：

- 源所有者
- 源 URL
- 访问方式
- 许可证或使用说明
- 模式（schema）说明
- 质量说明
- 最近一次验证日期

## 7. 推荐的初始数据策略

建议从以下内容开始：

1. 一个经过人工验证的小型问答表
2. 一个用于规模测试的公开基准数据集
3. 一个用于 RAG 行为测试的文档或网站知识源

这样可以提供：

- 一个高度可信的源
- 一个大型结构化源
- 一个半结构化源

## 8. 原始数据存储建议

不要立即将下载的大型语料库提交到源码目录中。

建议采用以下未来的目录布局：

```text
StudyQuestionBankAssistant/
  data/
    raw/
    staged/
    normalized/
    manifests/
```

除非所选数据集的许可证明确允许捆绑，否则仅在版本控制中存储轻量级的清单文件（manifests）和文档。
