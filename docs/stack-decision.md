# 技术栈决策

更新日期：`2026-06-07`

## 决策范围

本文档记录项目从研究阶段进入可运行实现后的主要技术栈选择。

## 决策摘要

已采用的核心路径：

- 应用层：FastAPI + Uvicorn 本地/服务端 HTTP 服务。
- 模型访问：兼容 OpenAI 的 `/chat/completions` 接口。
- 模型提供商：托管 API、Ollama、LM Studio、vLLM 或兼容网关。
- 检索能力：本地题库精确/近似检索、RAG 辅助和可配置联网搜索。
- 客户端目标：兼容 OCS 的 `/ocs/query` 题库配置。

## 选择原因

- 服务端统一保存模型密钥和题库数据，避免浏览器端暴露敏感信息。
- OpenAI 兼容协议便于切换不同模型提供商。
- FastAPI 与 Uvicorn 适合当前接口规模，启动和部署路径清晰。
- 题库、AI 作答、联网搜索拆分为独立能力，便于后续调优和测试。
