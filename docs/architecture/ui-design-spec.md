# UI 设计规范

本文档为 StudyQuestionBankAssistant 的 Web 管理前端设计规范。

---

## 1. 设计系统与技术栈

- **前端框架**：Vue 3 (Composition API + `<script setup>`)
- **构建工具**：Vite
- **UI 组件库**：Element Plus
- **设计风格**：现代暗色/亮色优雅卡片式布局，侧重数据展示、高密度操作和清晰的系统状态监控。

---

## 2. 页面布局与导航规范

### 2.1 整体架构
- **侧边栏导航**：包含仪表盘、题库检索、模型配置、API Token 管理、系统日志与监控、系统设置。
- **顶部顶栏**：显示当前页面标题、面包屑、环境状态、当前登录用户与退出按钮。
- **页面主体**：采用响应式流式布局，主卡片提供平滑阴影与圆角。

### 2.2 移动端与响应式适配
- 在窄屏或移动端下：
  - `PageHeader` 按钮组自适应换行，标题保持弹性收缩（`flex: 1; min-width: 0`），避免标题字符垂直挤压。
  - 复杂表格隐藏非核心列或转换为卡片列表展示。
  - 侧边栏折叠为抽屉导航。

---

## 3. 核心视图设计

### 3.1 题库与检索控制台
- 支持问题文本高亮分词匹配。
- 候选答案展示包含可信度评分、命中文档片段与来源标识。

### 3.2 令牌与权限管理 (`TokensView`)
- 支持 Token 余额限制、失效期管理。
- **单设备独占绑定**：开启后绑定首次调用的客户端指纹；重置或关闭时清空绑定状态。

### 3.3 日志与调用监控 (`SystemLogsView`)
- **双视图模式**：
  1. **业务调用日志**：表格分页展示，点击单行右侧抽屉拉出详细上下文与请求体/响应体，带一键复制与长文本自动换行。
  2. **终端实时日志**：仿真 Linux 控制台输出，支持色彩标签分级、自动滚屏与一键清屏。

### 3.4 账户安全与人机验证
- 登录/注册支持动态拼图滑动验证码（Slider Captcha）。
- 当连续登录失败达到系统阈值时自动弹出验证码。

---

## 4. 色彩与排版规范

- **主色调**：`#409EFF` (Brand Blue)
- **成功状态**：`#67C23A`
- **警告状态**：`#E6A23C`
- **危险状态**：`#F56C6C`
- **中性灰度**：
  - 标题与正文：`#303133` / `#606266`
  - 辅助文字：`#909399`
  - 边框与分割线：`#DCDFE6` / `#EBEEF5`
