# API Key 指南：什么是 API Key 以及如何创建

在使用外部脚本或插件（如 OCS 网课助手、油猴 Tampermonkey 脚本）配合本平台进行自动化题目检索时，**API Key（应用令牌）** 是核心枢纽。

---

## 1. 什么是 API Key？它是拿来做什么的？

### 🔑 通俗理解：专属免密电子通行证
你可以把 **API Key** 想象成一张专门给脚本使用的**房卡或通行证**：
- 当你在浏览器脚本中配置本系统作为题库检索源时，脚本必须携带这一串凭证（通常以 `sk-` 开头），服务器才会放行并为你提供搜题服务；
- 脚本调用搜题所消耗的积分，会直接扣除在该 API Key 所归属的账号上。

### 🛡️ 为什么不直接在脚本里输入账号密码？
1. **极大提升账号安全性**：第三方脚本代码或网络环境可能存在被拦截或泄漏的风险。使用 API Key 能够完全隔离你的账号登录密码。
2. **支持随时吊销与停用**：一旦怀疑某个设备上的脚本或 Key 泄漏，你只需在后台单键吊销该 API Key，无需更改主账号密码，其他 Key 也不会受影响。
3. **调用额度与风控限制**：你可以为单个 Key 设定最大使用次数限制（例如 200 次），防止脚本由于异常死循环无限搜题耗光你的钱包积分。
4. **防乱答与置信度过滤**：可设置“低于指定置信度拒绝返回答案”，防止 AI 在不确定的情况下盲目作答导致扣减积分。

---

## 2. 如何创建 API Key？（手把手教程）

你可以直接点击链接前往 [API Key 管理](/tokens) 页面进行创建，具体步骤如下：

### 步骤一：进入管理页面
登录平台后，在左侧导航栏点击「个人中心」 -> 「[API Key 管理](/tokens)」。

### 步骤二：点击「新建 API Key」
在页面右上角点击 **「新建 API Key」** 按钮，会弹出一个配置对话框：
- **用途备注**：建议填写清晰的使用场景或设备名称（如 `寝室台式机-OCS脚本`、`笔记本-油猴`），便于后期管理。
- **配额限制**：
  - 输入 `-1` 代表**不限额度**（直到钱包积分耗尽或天数到期）；
  - 输入具体数字（如 `500`）代表该 Key 最多累计只能调用 500 次，达到后自动停用。
- **拒绝低置信度答案**（推荐开启）：
  - 勾选后，可以设定一个最小置信度阈值（例如 `0.6`）；
  - 当题库或 AI 检索到的答案可信度低于该分数时，系统将直接返回未匹配到可靠答案，**且不会扣除你的积分**，避免误导作答。

### 步骤三：保存并复制密钥（⚠️ 核心重点）
点击确定提交后，系统会弹窗展示生成的完整密钥明文（形如 `sk-09a8b7...`）。之后也可以在 API Key 列表中对仍处于正常状态的可恢复密钥点击「复制」，无需重新登录或手动录入。

> ⚠️ **重要警告**：API Key 等同于账号的调用凭证。不要把它发到公开群聊、截图或提交到代码仓库；如果怀疑泄漏，请立即吊销并重新创建。

## 3. 如何将 API Key 接入答题脚本？

在获取到 API Key 后，你需要将其配置到对应的外部工具中。

### 方式一：一键复制 OCS 配置代码
在创建成功弹窗或点击对应 Key 的「复制配置」按钮中，系统已为你预先生成了标准的 OCS 配置片段，直接粘贴到 OCS 的题库设置中即可。

### 方式二：手动配置到通用接口
若使用的脚本支持通用自定义题库接口，配置参数一般如下：
- **接口地址 (URL)**：`https://你的站点域名/api/v1/query`
- **请求方法 (Method)**：`POST`
- **请求头 (Headers)**：
  ```http
  Authorization: Bearer 你的_API_Key
  Content-Type: application/json
  ```
- **请求体 (Body)**：标准 JSON 格式，包含题目文本 `title`。

## 4. API Key 的日常维护

- **查看调用量与状态**：在 [API Key 管理](/tokens) 列表可随时查看每个 Key 的创建时间、当前状态（正常/已吊销）、已使用次数及剩余额度。
- **分享接入配置**：点击「复制导入」打开配置弹窗后，可生成长期分享链接。链接只在浏览器地址片段中携带 Key；吊销或删除 Key 后，已分享的配置会立即失效。
- **停用与吊销**：点击「编辑」可更改使用限额与置信度规则；点击「吊销」会使该 Key 永久失效。
- **查看消费流水**：前往 [使用记录](/usage-logs) 页面，可根据时间与题目溯源每一笔调用详情。
