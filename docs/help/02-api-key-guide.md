# API Key 指南：什么是 API Key 以及如何创建

在 OCS 网课助手或其他兼容客户端中接入本平台题库时，**API Key（应用令牌）** 是用于识别账号和计量调用的凭证。

---

## 1. 什么是 API Key？它是拿来做什么的？

### 🔑 通俗理解：专属免密电子通行证
你可以把 **API Key** 想象成专门给外部客户端使用的**通行证**：
- 在 OCS 配置本系统作为题库来源时，请求会携带该凭证，服务端据此识别账号并提供搜题服务；
- 通过该 Key 调用搜题所消耗的积分，会计入 Key 所属账号。

### 🛡️ 为什么不直接在客户端里输入账号密码？
1. **隔离登录凭证**：客户端只需使用 API Key，不需要接触你的账号密码。
2. **支持随时启用与停用**：一旦怀疑某个设备上的脚本或 Key 泄漏，你只需在后台编辑 API Key 并将其禁用，无需更改主账号密码，其他 Key 也不会受影响。
3. **调用额度与风控限制**：你可以为单个 Key 设定最大使用次数限制（例如 200 次），防止脚本由于异常死循环无限搜题耗光你的钱包积分。
4. **防乱答与置信度过滤**：可设置“低于指定置信度拒绝返回答案”，防止 AI 在不确定的情况下盲目作答导致扣减积分。

---

## 2. 如何创建 API Key？（手把手教程）

你可以直接点击链接前往 [API Key 管理](/tokens) 页面进行创建，具体步骤如下：

### 步骤一：进入管理页面
登录平台后，在左侧导航栏点击「个人中心」 -> 「[API Key 管理](/tokens)」。

### 步骤二：点击「新建 API Key」
在页面右上角点击 **「新建 API Key」** 按钮，会弹出一个配置对话框：
- **用途备注**：建议填写清晰的使用场景或设备名称（如 `OCS-笔记本`），便于后期管理。
- **配额限制**：
  - 输入 `-1` 代表**不限额度**（直到钱包积分耗尽或天数到期）；
  - 输入具体数字（如 `500`）代表该 Key 最多累计只能调用 500 次，达到后自动停用。
- **拒绝低置信度答案**（推荐开启）：
  - 勾选后，可以设定一个最小置信度阈值（例如 `0.6`）；
  - 当题库或 AI 检索到的答案可信度低于该分数时，系统将直接返回未匹配到可靠答案，**且不会扣除你的积分**，避免误导作答。

### 步骤三：保存并复制密钥（⚠️ 核心重点）
点击确定提交后，系统会弹窗展示生成的完整密钥明文（形如 `sk-09a8b7...`）。之后也可以在 API Key 列表中对仍处于正常状态的可恢复密钥点击「复制」，无需重新登录或手动录入。

> ⚠️ **重要警告**：API Key 等同于账号的调用凭证。不要把它发到公开群聊、截图或提交到代码仓库；如果怀疑泄漏，请立即禁用并重新创建。

## 3. 如何将 API Key 接入 OCS？

创建 API Key 后，可复制自动生成的 OCS 配置并粘贴到 OCS 的题库设置中。

### 方式一：复制 OCS 配置
在创建成功弹窗或 API Key 列表中打开「复制 OCS 配置」，复制配置片段后粘贴到 OCS 的题库设置中。

### 方式二：手动配置到通用接口
其他兼容客户端也可以调用标准查询接口，参数如下：
- **接口地址 (URL)**：`https://你的站点域名/api/v1/query`，具体请求和响应契约见[查询接口文档](../architecture/apis/query.md)
- **请求方法 (Method)**：`POST`
- **请求头 (Headers)**：
  ```http
  Authorization: Bearer 你的_API_Key
  Content-Type: application/json
  ```
- **请求体 (Body)**：标准 JSON 格式，包含题目文本 `title`。

## 4. API Key 的日常维护

- **查看调用量与状态**：在 [API Key 管理](/tokens) 列表可随时查看每个 Key 的创建时间、当前状态（正常/已禁用）、已使用次数及剩余额度。
- **分享接入配置**：点击「复制 OCS 配置」打开配置弹窗后，可生成长期分享链接。链接只在浏览器地址片段中携带 Key；禁用或删除 Key 后，已分享的配置会立即失效。
- **启用与禁用**：点击「编辑」可更改使用限额、置信度规则和访问状态；禁用会立即阻止该 Key 调用，之后仍可在编辑弹窗中重新启用。
- **查看消费流水**：前往 [使用记录](/usage-logs) 页面，可根据时间与题目溯源每一笔调用详情。
