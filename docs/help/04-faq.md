# 常见问题排查 (FAQ)

本文整理了用户在日常使用题库助手、配置脚本及搜题过程中最常遇到的疑问与解决方法。

---

## 1. 搜题与答案相关

### ❓ 题目搜不到答案是什么原因？
1. **题库尚未收录**：部分最新试题、小众专业课或由教师私有出题的题目可能尚未纳入知识库；
2. **题目格式干扰**：若题目包含大段选项或特殊前缀（如“单选题（5分）”），建议适当删减，只保留最核心的题干文字；
3. **AI 正在生成或置信度过滤**：如果开启了大模型补全或 API Key 设置了较高的最低置信度阈值，当模型把握较低时为防止扣除积分会自动跳过。

### ❓ 搜题返回了答案，但为什么扣除了积分？
只要系统成功检索出有效答案并返回给客户端，就会按规则结算。若需要不限次数搜题，建议前往 [我的钱包](/wallet) 兑换天数会员卡。

## 2. API Key 与自动化脚本相关

### ❓ 脚本提示 `401 Unauthorized` 或 `认证失败`？
- 检查填入脚本的 API Key 是否带有前后空格；
- 检查 API Key 是否已被误操作“吊销”或删除，可前往 [API Key 管理](/tokens) 查看状态。

### ❓ 脚本提示 `403 Quota Exceeded` 或 `额度已用尽`？
- 说明在创建 API Key 时设置了配额上限（如 100 次），且当前已达到上限；
- 解决方法：在 [API Key 管理](/tokens) 页面点击该 Key 后的「编辑」，将配额上限改为 `-1`（不限）或调大数字。

### ❓ API Key 忘记了明文怎么办？
仍处于正常状态且支持恢复的 API Key 可以在 [API Key 管理](/tokens) 页面重新复制；旧数据库中只有哈希、没有可恢复原文的密钥无法恢复，请吊销旧密钥并点击右上角「新建 API Key」重新生成。

## 3. 账号与登录相关

### ❓ 忘记密码怎么找回？
前往登录界面，点击「[找回密码](/forgot)」即可通过绑定的邮箱验证码完成密码重置。
