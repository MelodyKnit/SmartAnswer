# 快速上手指南

欢迎使用智能题库助手！本平台致力于为广大学生及学习者提供高效、准确的在线搜题与辅助学习检索服务。

---

## 核心功能一览

平台主要提供以下功能模块：

1. **[在线搜题](/search)**：直接在网页端输入题目、选项或关键词，快速检索答案与解析。
2. **[AI 生图](/image-generation)**：利用前沿大模型能力，根据文本提示词快速生成概念图、示意图。
3. **[API Key 管理](/tokens)**：为浏览器自动化脚本（如 OCS 脚本、油猴脚本）生成专属调用密钥。
4. **[我的钱包](/wallet)**：管理题库检索积分、查看无限次免费搜题天数有效期限，以及使用兑换码核销权益。
5. **[使用记录](/usage-logs)**：清晰记录每一笔搜题检索耗时、结果及积分变动明细。

---

## 新手接入三部曲

对于想要配合脚本进行自动化刷题、检索题库的新用户，推荐按照以下流程操作：

1. **获取权益**：通过管理员分享的兑换码，在 [我的钱包](/wallet) 进行核销，充值积分或开通会员天数。详细指引请参考 [兑换码使用指南](/help?article=redeem-guide)。
2. **创建密钥**：前往 [API Key 管理](/tokens) 页面，创建专属于你的 API Key（免密通行证）。详细指引请参考 [API Key 指南](/help?article=api-key-guide)。
3. **配置脚本**：将生成的 API Key 填入你所使用的浏览器网课或答题脚本中，即可开启秒级自动搜题！

---

> 💡 **提示**：如果在使用过程中遇到任何异常或错题，欢迎前往 [反馈中心](/feedback) 提交工单，我们将持续优化检索模型与题库准确率。
