# 兑换码使用指南：权益兑换与规则说明

兑换码是平台用于充值搜题积分、延长无限搜题会员天数的重要凭据。本文将为你详细介绍兑换码的作用、使用方式及扣费规则。

---

## 1. 什么是兑换码？

兑换码是由管理员或系统活动派发的一串专属字符（如 `REDEEM-XXXX-YYYY`）。

兑换码通常包含以下两种权益类型之一（或两者兼备）：
- **充值积分**：兑换后为你增加指定数额的搜题点数（按题检索扣除）。
- **增加天数（会员期）**：兑换后在你的账户有效期上叠加指定天数。在天数有效期内，**全站搜题无限次免费**！

---

## 2. 如何使用兑换码？

平台提供了两种极为简便的兑换方式：

### 方式一：站内手动核销（推荐）
如果你已经拥有账号并处于登录状态：
1. 点击左侧导航栏的「个人中心」 -> 「[我的钱包](/wallet)」；
2. 页面顶部第三个卡片即为 **「兑换码核销」**；
3. 将收到的兑换码完整粘贴到输入框中；
4. 点击 **「兑换」** 按钮，系统会即时完成核销；
5. 成功后，左侧的「当前积分」或「天数有效期」将实时刷新增加，下方流水列表也会新增一条对应的充值记录。

---

### 方式二：免登录直达链接兑换
如果管理员或朋友发给你的是一个类似下面的直达分享链接：
`https://站点域名/share/redeem#code=REDEEM-XXXX-YYYY`

操作流程如下：
1. 直接在浏览器打开该链接，页面会在浏览器本地读取并锁定兑换码；
2. 若当前未登录，系统会引导你先进行登录或注册；
3. 登录完成后，页面会自动执行兑换流程，无需进入钱包或再次点击兑换按钮。

---

## 3. 权益扣减与消费优先级规则

为了保障用户利益，系统设计了合理的权益消耗优先级：

```text
用户发起搜题请求
       │
       ▼
是否处于【无限天数有效期】内？
    ├── 是 ──► 免除积分扣除，免费直接获取答案
    └── 否 ──► 扣除 1 点钱包积分（积分不足则无法搜题）
```

- **会员天数期间**：只要剩余天数大于 0，任何通过网页端搜题或 API Key 调用的有效搜题均享受免费无限次权益，不会消耗你账户现有的剩余积分。
- **天数到期后**：会员天数到期后，系统自动平滑回退为按次扣除钱包内的积分。
- **生图权益**：AI 高清生图功能扣费以系统配置的实际积分点数为准。

## 4. 常见问题排查 (FAQ)

### Q1: 提示“兑换码不存在或已失效”？
- 请检查是否复制了多余的前后空格；
- 兑换码通常区分英文大小写，请确保完整复制；
- 确认该兑换码是否已在其他账号或之前被核销过（大多数兑换码为一次性使用）。

### Q2: 提示“兑换码已被使用”？
- 兑换码一经成功核销即会作废，无法重复使用。请前往 [我的钱包](/wallet) 下方的「权益变更流水」查看是否已经充值成功。

### Q3: 充值之后可以退款或转移到其他账号吗？
- 兑换成功后，积分与天数将直接绑定当前登录账户，不支持跨账号转移或撤销，请在兑换前确认当前登录的账户是否正确。
