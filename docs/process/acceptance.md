# 验收工作流

更新时间：`2026-06-07`

## 1. 目的

本文档只保留当前项目的测试边界说明，不再维护旧的验收脚本说明。

## 2. 当前验证方式

当前主要验证方式：

- `python -m pytest tests -q`
- 运行中的 `/healthz`
- 运行中的 `/status`
- 运行中的 `/ocs/query`

## 3. 当前验证覆盖

当前测试覆盖重点：

- FastAPI 路由边界
- OCS 返回结构
- 多选答案顺序规范化
- 填空题脏 `options` 清理
- 单空 / 多空填空返回格式
- AI 学习题库与缓存晋升
- 运行时日志和环境加载

## 4. 仍需真实环境验证的部分

以下内容仍然依赖真实外部环境，而不是单元测试即可证明：

- 真实 OCS/Tampermonkey 页面回填行为
- 真实云模型网关的可用性与稳定性
- 本地模型运行时（如 Ollama / LM Studio）的真实接入
