# 生图任务编排

本包负责文本生图的任务状态、积分结算和后台轮询，不负责供应商 HTTP 协议或图片文件格式。

- `service.py`：模型管理、协议/输出参数归一、任务创建、预扣/确认/退款、私有资产授权和过期清理。
- `worker.py`：应用生命周期内的单消费者轮询和中断任务恢复。
- `records.py`：领域记录类型。

任务必须遵循以下边界：提交时原子预扣，成功持久化至少一个图片资产后确认；拒绝、超时、校验或存储失败均退款。已提交供应商的任务不自动重试或切换模型，用户重新生成才会创建新任务。生成资产仅通过鉴权 API 提供给所有者或管理员，文件保存在运行数据目录 `data/images/generations`。

模型记录保存非敏感 `protocol_config`，任务保存已经校验的 `output_options` 快照。队列执行时使用
提交时的协议、模型地址、模型标识和输出参数，API Key 仍从当前受控模型记录读取。这样管理员后续编辑
模型不会让已排队任务隐式改变画幅、像素档位或尺寸；密钥也不会复制到任务、日志或调用追溯。
