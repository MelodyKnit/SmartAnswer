                          支持的关键词
═══════════════════════════════════════════════════════════════════════════

  📐 画幅比例识别 (55+ 关键词)

    1:1   → 正方形、方形、头像、logo、图标、instagram、微信
            square, profile, avatar, icon

    16:9  → 横屏、宽屏、电影、视频、YouTube、桌面壁纸、banner
            landscape, widescreen, cinematic, video, cover

    9:16  → 竖屏、手机、竖版、短视频、抖音、快手、stories
            portrait, vertical, mobile, phone, reels

    21:9  → 超宽、全景、panoramic, ultrawide

    3:2   → 相机、摄影、照片、photography, camera

    4:3   → 传统、经典、演示、PPT、presentation

  📏 复杂度识别 (30+ 关键词)

    高 → 详细、复杂、精致、细节丰富、宏大、史诗、城市、人群
         detailed, complex, intricate, elaborate, epic, cityscape
         → 推荐 4K / 2K

    中 → 场景、环境、人物、角色、动物
         scene, environment, character, person, animal
         → 推荐 1K

    低 → 简单、极简、单色、图标、logo、抽象
         simple, minimal, minimalist, icon, flat, abstract
         → 推荐 512
